# Design hierarchy and rhythm

Read the file and styles; note the medium (page, slide, mobile, dashboard). Report every issue with confidence and severity, then fix.

**Hierarchy**
- Name the primary, secondary, tertiary reads. If you cannot, it is broken.
- Size: headings clearly above body, primary CTA above secondary. Flag flat sizes and inconsistent ones.
- Color and weight: strongest signal on the most important element; flag everything-bold, everything-same-color, and loud unimportant elements.
- Position and density: key content in prime space, with room; crammed important content beside airy filler is reversed.
- 5-second test: a newcomer knows where to look and what to do.

**Rhythm**
- Spacing and type values snap to one scale; list the scale in use and flag outliers.
- Repeated items (cards, rows) are identical or clearly different, never nearly the same.
- Break the pattern once, on purpose (a background shift, a wider block). All-uniform is dull, all-different is chaotic.
- 3-5 colors plus tints; flag 8+ or near-duplicate shades.
- Sections are separated in one consistent way. Flag a few-pixel misalignment.

**Content**
- Hierarchy needs something to rank. If the first read is vague, or the page is too thin to have a second and third read, write the missing content (/design-principles) instead of restyling what is there.
- An empty or broken image box takes the eye for nothing: replace it with something real or remove it.

**Fix:** snap to the scale (define one if missing); add contrast where flat; swap signals where reversed. When unsure, go stronger; it is easier to dial back. Then look at a render at desktop width and 375px and confirm the first read is the one you intended. Summarize fixes and judgment calls.
