# Design brief

Ask one consolidated round, then work on your own. Skip every question the request or attached files already answer; if nothing is unclear, ask nothing.

Cover only what is missing:
1. **Output:** page, app screen, deck, prototype, component? Fidelity (wireframe or polished)?
2. **Audience and goal:** who uses it, what should they do first?
3. **Context:** brand, design system, codebase, screenshots, references to match or avoid?
4. **Options:** how many variations, and which axes should differ?
5. **Constraints:** devices, content that must appear, tech stack, deadline.

If the user is unavailable or says "just decide", pick a reasonable default for each gap and list the assumptions at the top of the output. Do not ask about minor choices; decide and note them.
